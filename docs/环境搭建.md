# 环境搭建

使用uv进行项目管理
```shell
uv venv # 创建虚拟环境
# 已有项目不需要再次 uv init
```

安装依赖库
```shell
uv pip install -r requirement.txt
```
uv pip install 不要求先激活虚拟环境。它按以下顺序寻找安装目标：
 1. 已激活的虚拟环境（VIRTUAL_ENV）。
 2. 已激活的 Conda 环境（CONDA_PREFIX）。
 3. 当前目录或最近上级目录中的 .venv。

如需明确安装到本项目的环境（Windows），无需激活：
```powershell
uv pip install --python .venv\Scripts\python.exe -r requirement.txt
```
Notebook 中选择 `.venv` 对应的 Python 内核。

Lab03 使用 `keras` 的公开导入路径（例如 `from keras.layers import Dense`），避免 Pylance 无法静态解析动态加载的 `tensorflow.keras`。
安装 TensorFlow 后，若仍提示无法解析 `import tensorflow`，确认编辑器解释器与 Notebook 内核均为本项目 `.venv`，再通过命令面板执行 `Python: Restart Language Server`；若无该命令，执行 `Developer: Reload Window`。

Lab03 概率图使用 `.item()` 显式取出单值 Tensor/数组中的数值，兼容新版 NumPy 的标量赋值要求。修改辅助模块后，Notebook 中需用 `importlib.reload` 重新加载模块并重新导入绘图函数；无需重新训练模型。

- 数值计算与绘图：`numpy`、`matplotlib`。
- 神经网络、数据处理与传统机器学习：`tensorflow>=2.16`、`pandas`、`scikit-learn`。
- Notebook 与交互绘图：`ipykernel`、`ipython`、`ipywidgets`、`ipympl`；后两项支持 Lab04、Lab05 的 `%matplotlib widget`。
- 表格、图像和视频：`tabulate`、`pillow`（导入名为 `PIL`）、`imageio[ffmpeg]`（包含 MP4 编码所需的 FFmpeg 插件）。
